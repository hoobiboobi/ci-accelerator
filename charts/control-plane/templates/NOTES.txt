A fleet hub (docs/fleet.md): one console for the boxes that join it. The
Deployment {{ $hub }} serves the pages, the management API
({{ $u }}/api/v1/fleet/) and the members' connections
({{ $u }}/fleet/v1/connect, a WebSocket) on its ClusterIP Service
{{ $hub }}, port {{ int .Values.web.port }}: put it behind your Ingress or gateway, with TLS and
WebSockets, at {{ $u }}.
{{- if include "control-plane.signIn" . }}

People sign in through GitLab at {{ $u }}/; the owners
(signIn.gitlab[].owners) see and manage the whole fleet. Each GitLab's
OAuth application must list this redirect URI:
{{- range .Values.signIn.gitlab }}
{{- if .url }}
  {{ .url }}: {{ $u }}/auth/callback/{{ sha256sum .url | trunc 6 }}
{{- else }}
  {{ first $.Values.gitlab.urls }}: {{ $u }}/auth/callback/<id> (the hub's log
  prints it: kubectl -n {{ $.Release.Namespace }} logs deploy/{{ $hub }} | grep redirect_uri)
{{- end }}
{{- end }}

{{- if not .Values.controller.persistence.existingClaim }}, which is kept when the release is removed{{ end }}.

A fleet member: the controller dials the hub at {{ $hubURL }} as
{{ dig "name" "" $f }} and serves it its API over that connection. This release
installs no web: the cluster's pages are at the hub,
{{ $hubURL }}/m/{{ dig "name" "" $f }}/, behind the hub's sign-in. The Secrets the

fleet-gitlab-token, fleet-s3-cache) are created here empty and filled

  kubectl -n {{ .Release.Namespace }} logs deploy/{{ $ctrl }} | grep fleet:

People sign in to the console through GitLab at {{ $u }}/ and see the
projects whose jobs GitLab lets them read; the JSON API
({{ $u }}/api/v1/builds) answers the admins. Each GitLab's OAuth
application must list this redirect URI:
{{- range .Values.signIn.gitlab }}
{{- if .url }}
  {{ .url }}: {{ $u }}/auth/callback/{{ sha256sum .url | trunc 6 }}
{{- else }}
  the runners' GitLab: {{ $u }}/auth/callback/<id> (the controller's log
  prints it: kubectl -n {{ $.Release.Namespace }} logs deploy/{{ $ctrl }} | grep redirect_uri)
{{- end }}
{{- end }}

The web serves plain HTTP on its ClusterIP Service {{ $web }}: put it
