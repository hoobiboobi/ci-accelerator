The runner puts every job's builds into its pipeline's trace. The trace of
pipeline <id>, with the port-forward above:
  curl -s http://localhost:10428/select/jaeger/api/traces/{{ $runner.gitlabUrl | sha256sum | trunc 16 }}$(printf '%016x' <id>)
{{- end }}
Builds can reach this storage: they can read other projects' traces (the
buildctl command line is recorded, so never pass secrets as build args) and
change or delete data. Do not expose it outside the cluster.
{{- end }}

Builds share the daemons' cache: a build's RUN steps can read and write what
other builds left there. Use one installation per trust domain.
